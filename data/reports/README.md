# 사전 작성한 동별 대응 설명

`heatwave/`는 부산 실제 분석에서 종합점수를 산출할 수 있는 동의 대응 설명입니다.
지역코드별 수치·자료·대응 항목의 검증값, 작성 시각, 모델·프롬프트 버전과 한국어 설명을 저장합니다.
배포할 때 백엔드에서 이 폴더를 읽을 수 있도록 함께 포함하세요. 조회에는 모델이 필요 없습니다.

생성: `.venv/bin/python scripts/prepare_reports.py`.
원문 응답은 Git에서 제외한 `data/raw/reports/`에 있습니다.
통계와 공식 자료가 변경되면 기존 문장을 재사용하지 않으며, 생성 스크립트로 다시 준비합니다.
자료가 부족한 동과 합성 데이터에 실제 모드의 설명을 사용하지 않습니다.

지표·점수·순위는 모델 출력이 아닙니다. 공식 출처와 실행 제안은
`backend/app/services/ai/guidance.py`에서 관리합니다.
