# 분석 기준과 한계

## 범위와 출처

실제 모드는 SGIS 인구·가구·주택 공간통계와 기상청 ASOS/AWS 관측자료를 결합한다. 모든 통계는 2024년이며 기상 기간은 6월 1일~8월 31일(KST, 92일)이다. 경계는 승인된 2025년 SGIS 경계다. 부산 223개 통계 코드(시 1, 구·군 16, 읍면동 206)가 모두 일치한다. 전국은 경계 탐색만 제공한다.

실제 자료와 Sample은 분리한다. Sample의 모든 통계는 합성이며 실제 경계만 사용한다. 지표별 출처와 원천 정보를 API와 화면에서 확인할 수 있다.

## 기상 관측소 연결

1. 2024년 여름의 위치 이력을 확인한 부산 관측소를 후보로 사용한다. 기간 중 위치가 여러 곳이면 자동 연결하지 않는다. 북부산(296)은 AWS에서 ASOS로 전환했으므로 2024년 AWS 위치 이력을 확인했다.
2. 지역 Polygon을 EPSG:5179로 변환하고 면적 중심을 구한다. 중심이 영역 밖이면 영역 내부 대표점을 사용한다. 구·군과 읍면동에 같은 방식을 적용한다.
3. 대표점에서 WGS84 타원체 거리가 가장 가까운 관측소를 연결한다. 관측소명·ID·거리·대표점·관측 기간·유효 일수를 보존한다.
4. 92일의 일 평균기온 평균을 여름 평균기온으로, 일 최고기온 33℃ 이상인 날의 수를 여름 폭염일수로 사용한다. 특보 발령 횟수는 사용하지 않는다.

연결한 관측소의 고도·지형·해안 환경은 동의 거주지역과 다를 수 있다. 인근 관측값을 동 자체의 직접 실측값으로 해석하면 안 된다. 같은 관측소를 연결한 동은 같은 기상값을 가지며, 공간 해상도를 인위적으로 높이지 않는다. 실시간 날씨가 아니라 2024년 통계 분석이다.

일 평균기온과 최고기온은 각각 92일이 모두 유효해야 해당 지표를 계산한다. 결측일을 0·평균·다른 관측소 값으로 대체하지 않는다. 최근접 관측소가 불완전하다고 더 먼 관측소로 자동 교체하지 않는다. 현재 종합점수는 구·군 14/16개, 읍면동 173/206개에서 계산된다.

## 노후주택

SGIS 살고싶은 우리동네 B005의 2024년 공개 비율을 그대로 사용한다. 정의는 건축 후 30년 이상 주택 / 전체 주택 × 100이다. 공식 자료는 소수 첫째 자리의 비율만 제공하므로 주택 수를 역산하지 않는다. 구·부산 비교값에는 같은 출처의 공식 상위지역 비율을 사용한다(사용자 승인).

주택 OpenAPI의 1990~1999년 구간을 임의 분할하지 않는다. KOSIS 수치는 교차 확인만 했고 일부 값이 달라 혼합하지 않았다. 일반 건축물과 주택을 같은 분모로 취급하지 않는다.

## 점수와 비교

같은 비교범위(부산 구·군, 선택 구·군의 읍면동)에서 지표를 Min–Max 정규화한다. 가중합 H/E/V의 곱을 다시 0~100으로 정규화한다. 같은 지표값은 0.5, 같은 최종 원점수는 50과 차이 없음 안내를 사용한다.

지표 하나라도 없으면 해당 그룹과 종합점수는 null이다. 최종 정규화·점수 평균·순위는 모든 필수 지표가 확보된 지역만 사용한다. UI에 산출 가능한 지역 수를 표시한다. 위험등급 경계는 반올림된 표시점수 기준 20/40/60/80을 다음 등급에 포함한다.

고령·1인가구의 비교 기준은 유효한 분자·분모의 합산 비율이다. 노후주택은 공식 지역 비율, 인구밀도는 인구/합산 면적, 총인구·기상지표는 유효 지역 산술평균이다. 위험점수는 확률·피해량·인과효과가 아니며 다른 비교범위의 점수끼리 직접 비교하지 않는다. 가중치는 실증적으로 교정하지 않은 MVP 설정이다.

## 요청 및 설명

운영 수집기는 외부 호스트별 최소 3초 요청 간격을 파일 잠금으로 공유한다. SGIS 인증 요청도 포함한다. HTTP 429는 Retry-After를 존중하고 없으면 30초를 기다린다. 통계는 캐시에서 제공하며 화면을 열 때마다 재수집하지 않는다. 기상청 정식 인증 API 전환과 실시간 화면은 별도 작업이다.

규칙 기반 설명은 서버가 계산한 값과 Top 3 요인에 연결된 대응 Catalog만 사용한다. 시설 존재·정책 시행·피해 발생을 생성하지 않는다. 인근 기상 관측소를 사용한다는 한계를 설명에도 표시한다.

## 기본 비교범위와 상세지도

첫 화면은 부산 206개 읍면동 전체를 하나의 비교집단으로 사용한다. 구·군 요약은 16개 구·군끼리, 구 상세는 해당 구의 읍면동끼리 비교한다. 순위·지도·상세 통계·규칙 설명은 같은 `level`과 상위지역을 전달받는다.

상세 도로지도는 OpenStreetMap 타일을 사용하며, 선택 지역의 통계 경계와 함께 보여준다. 도로지도의 현재 지형·도로 표시는 2024년 분석 통계의 원본이 아니다. 타일은 브라우저에서 현재 화면에 필요한 것만 요청하고 캐시 헤더를 따른다. 자동 브라우저 테스트에서는 타일 요청을 대체하여 수집하지 않는다.

## 기온 표시와 지도 축척

기온 그래프는 점수에 이미 연결한 최근접 관측소의 2024년 6~8월 일별 최고·최저를 사용한다. 기존 최고기온 캐시는 그대로 사용하고 최저기온만 동일 기상청 공개 조회에서 보완했다. 14개 연결 관측소 중 최고·최저 각각 92일 완비는 10개다. 기간 극값은 해당 계열이 모두 유효할 때만 산출하고, 최대/최소가 같은 날짜는 모두 반환한다. 일별 결측은 null로 남겨 그래프에 연결선을 만들지 않는다. 점수 계산은 기존 평균기온·폭염일수 그대로다.

부산 전체 동 분석과 현재 시설 지도는 확대 수준 11.4를 기준으로 구·군과 읍·면·동 경계·이름을 전환한다. 구·군 색상은 기존 구·군 비교 결과, 동별 색상은 현재 동별 비교 결과이며 범례에 표시 단위를 명시한다. 왼쪽 순위의 비교범위는 줌과 무관하게 유지한다. 구·군 색상을 동별 평균으로 역산하지 않는다.

자동 지역 분석보고서는 비교범위를 부산 전체 읍면동으로 고정한다. 순위는 유효 점수가 더 큰 동의 수 + 1이며 동점은 동일 순위다. 현장 확인 사항은 확보된 상위 요인에 연결해 읽기 전용으로 제공한다. 시설 부족이나 설치 위치의 확정 결과가 아니다.


## 2026년 현재 기상·시설

현재 기상은 2024년 점수와 독립된 관측소별 기록이다. 최근 30일과 6~8월 자료를 제공하며, 기간 최고/최저는 각 지표가 전 기간 유효할 때만 제공한다. 폭염일수도 최고기온이 전 기간 있어야 계산한다. 현재 위치는 해당 조회일을 포함하는 기상청 이력으로 확인하며 위치 불명확 지점은 지도에서 제외한다.
