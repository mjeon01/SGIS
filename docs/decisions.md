## 동별 대응 및 화면 개편 (추가 확인)

- 목적은 특정 건물 입지 선정이 아닌 **동별 우선 대응지역 탐색**이다. 기본 화면은 부산 전체 읍면동을 같은 범위로 정규화한 지도·순위로 한다. 구·군 요약과 구 내부 비교는 명시적으로 전환한다.
- SGIS `https://sgis.mods.go.kr/view/house/houseAnalysisMap`을 참고하여 메뉴·지역 선택·상세 분석을 왼쪽에서 전환한다. 오른쪽 고정 데이터보드는 제거한다.
- 상세 도로지도에서 기존 시설 위치를 확인하는 기능을 요청했다. 특정 신규 설치 후보 지점은 표시하지 않는다.
- 확충 검토 순위는 기존 취약도 순위를 유지한다. 누구나 이용할 수 있는 쉼터 수와 인구 대비 시설 수를 나란히 비교하는 방향을 승인했다. 시설 개수만으로 부족 여부를 판정하거나 새로운 가중합 점수를 도입하지 않는다.
- 2024년 취약도에 2026년 시설자료를 결합하는 제안에 사용자가 혼동을 지적했다. 후속 확인에서 **2026년 시설은 별도 ‘현재 시설’ 화면에서 제공하며, 2024년 취약도·인구와 수치 비교하지 않음**을 승인했다. 따라서 시설 수/인구 비율 비교는 적용하지 않는다.

## 축척·기온·지역 분석보고서 (추가 승인)

- 지역명과 경계 모두 축척에 따라 전환한다. 부산 읍면동 분석과 현재 시설 화면은 지도 확대 수준 11.4 미만에서 구·군, 이상에서 읍·면·동을 표시한다. 줌은 동별 우선순위를 변경하지 않는다. 명시적인 구·군 요약 비교도 확대하면 동 경계를 보여주되, 비교범위는 사용자가 동을 선택할 때 전환한다.
- 기온 표시는 2024년 6~8월 일별 최고·최저 그래프와 기간 최고·최저값으로 보완한다. 종합 취약도 계산의 여름 평균기온·폭염일수는 유지한다. 최저기온은 동일 기상청 관측소의 일별 자료를 3초 간격으로 보완 수집한다.
- 기간 극값은 해당 최고/최저기온이 92일 모두 유효한 경우만 제공한다. 일별 결측은 그래프에서 선으로 잇지 않고 표에도 결측으로 표시한다.
- 동별 보고서는 부산 전체 읍면동 기준 순위, 주요 근거, 규칙 기반 대응 방향, 현장 확인 사항을 읽는 **자동 지역 분석보고서**로 제공한다. 후속 사용자 요청에 따라 체크박스·메모 입력을 제거했다. Markdown 저장과 해당 동의 현재 시설 화면 왕복 이동은 유지한다. 결측 동은 순위가 없으며 Sample에는 실제 시설 바로가기를 제공하지 않는다.

## 현재 기상·운영조건·보행 접근성 (추가 승인)

- 2026년 최근 기온과 여름 기록은 별도 ‘현재 기상’ 화면에서 제공한다. 2024년 취약도 계산에 혼합하지 않는다.
- 기상청 ASOS/AWS의 관측소별 일 최고·최저기온을 사용한다. 최근 30일과 6~8월 기록, 각 관측소 마지막 관측일·유효 일수·조회 종료일·저장 시각을 구분한다. 완료된 일 관측자료이며 실시간 순간 기온으로 표현하지 않는다.
- 관측소 위치는 현재 조회일의 기상청 위치 이력으로 확인한다. 2024년 위치를 재사용하지 않으며 현재 위치가 불명확하면 지도에 임의 배치하지 않는다.
- 화면의 갱신 버튼으로 백엔드 수집 작업을 시작한다. 기상청 요청은 최소 3초 간격, 429 대기, 6시간 캐시 재사용, 중복 작업 방지, 원자적 저장을 적용한다. 실패 시 기존 스냅샷을 유지한다.
- 현재 시설에서 쉼터 이용대상·등록 운영요일·시간으로 확인한다. 평일/주말 시간을 구분하며 미등록 정보는 ‘조건 확인 필요’로 표시한다. 공휴일·특보 시 특별운영과 실시간 개방 여부는 판정하지 않는다.
- **보행경로 거리 기본 500m, 화면에서 250m·500m·1km 선택**을 사용자 승인으로 적용한다. 접근성을 켜면 ‘누구나 이용 가능한 쉼터’ 조건으로 시작하며 사용자가 변경할 수 있다.
- 2026년 시설과 OSM 보행망으로 계산한다. 사용자가 선택한 구·군/동의 경로를 표시하되 주변 부산 쉼터도 계산에 포함한다. 2024년 인구·취약도와 수치 비교하지 않는다.
- 거리 이내 경로, 선택 조건에서 거리 이내 경로 미확인, 운영·이용조건 확인 필요를 구분한다. 시설 부족이나 신규 설치 위치를 확정하지 않는다.
- 구현상 등록 좌표를 가장 가까운 보행선에 최대 100m까지 연결하고 연결거리도 경로 길이에 포함한다. 연결 불가 시설은 제외 수를 표시한다. OSM 연결 노드를 보존하고 보행 금지·사유 출입제한·불명확한 조건부 통행은 제외한다. 차량 일방통행을 보행에 강제하지 않으며 명시적 보행 일방통행만 적용한다.
- OSM 보행망 누락, 부산 밖 시설, 실제 출입구, 경사, 장애물, 고가·지하 접근, 임시 통제는 반영하지 않는다. 이 한계는 화면 및 API에 표시한다. 길이 없는 면적을 보행 가능 영역으로 채우지 않는다.


## 동네 분석 안의 현재 기상 (2026-09-23 후속 요청)

- 현재 기상을 동네 분석에서도 확인하도록 사용자가 요청했다. ‘위험현황’ 상단에 최신 일 최고·최저 요약을, ‘현재기상’ 탭에 최근 30일·올여름 그래프와 관측표·갱신 기능을 제공한다. 기존 관측소 전체 지도도 유지한다.
- 선택한 실제 부산 읍면동의 내부 대표점에서 현재 조회일에 위치가 확인된 최근접 기상청 관측소를 연결한다. 2024년 분석 당시 관측소 위치를 재사용하지 않는다. 가까운 관측소가 결측이어도 더 먼 관측소로 대체하지 않는다.
- 최신 관측일·연도·관측소명·대표점과 거리·저장 시각을 명시하며 동 자체의 실측값으로 표시하지 않는다. 최신 관측값이 조회 종료일보다 오래되었거나 파일 갱신이 필요하면 별도로 알린다.
- 현재 기상 표시를 추가해도 2024년 취약도 점수와 보고서 근거는 바꾸지 않는다. Sample과 부산 외 지역에는 실제 동별 기상을 임의로 연결하지 않는다.


## 보행 접근성 전체 제거 (2026-09-23 최종 요청)

사용자가 색칠된 보행로와 거리 선택을 포함한 보행 접근성 기능 전체 제거를 명시했다. 앞서 승인한 접근성 계획을 대체하며, 지도 선·범례·거리 선택·계산 API·전용 수집/전처리 코드를 제거한다. 현재 시설은 쉼터·그늘막 좌표와 이용대상·운영요일·시간 필터를 제공한다. 기존 취약도, 현재 기상, 보고서 기능은 계속 제공한다.

## 침수 확장과 탐색 메뉴 정리 (2026-09-23 후속 요청)

- 사용자가 침수부터 확장하도록 요청하고, **과거 침수 이력과 예상도를 각각 구분해 제공**하도록 선택했다. 폭염 점수·인구·통계와 혼합하거나 새로운 침수 우선순위 공식을 만들지 않는다.
- 부산 안전 ON의 과거 기록은 면적 폴리곤이 아닌 대표 지점으로 제공한다. 발생 연도·구군·동 필터, 지점 상세의 발생 기간·원인·기록된 깊이·면적을 제공한다. 유효한 좌표 186건을 표시하며 날짜가 불명확한 1건은 연도 확인 필요로 분리한다. 좌표 오류 2건을 제외하고 행정동에 유일하게 속하지 않는 1건은 부산 전체에서만 확인한다.
- 예상도는 공식 도심침수 WMS의 `fldm_30/50/80/100` 원본을 저장한다. 공식 화면의 98.1/106.8/114.7/118.5mm/h 시나리오와 침수심 범례를 사용한다. 첫 번째 30년 빈도로 시작하고 사용자가 변경한다. 실시간 침수·예보·개별 건물 판정으로 표현하지 않는다. WFS 비활성화를 확인한 뒤 추가 WFS 조회를 하지 않았다.
- 전체 부산 영상 4,096×4,096 픽셀을 사용한다. 원본 제작 기준연도는 확인되지 않았으며 수집일을 제작연도로 오인하지 않는다. 확대 표시 한계·출처는 데이터 안내에 제공한다. 외부 호출은 호스트별 최소 3초 간격이고 화면 조회는 저장 자료만 읽는다.
- 왼쪽 상단에서 폭염/침수를 전환하고 동네 이름 검색(키보드 방향키·Enter 지원)으로 바로 이동한다. 지역 선택은 즉시 반영하며 별도 분석하기 클릭을 제거한다. 폭염 분석에서 시설을 확인한 후 지역 탐색/동네 분석으로 돌아가면 기존 선택을 복원한다.
- 사용자 요청에 따라 통계·경계 연도 반복 배지와 규칙 기반/LLM 구현 문구를 주 화면·보고서에서 제거한다. 통계·경계 기준은 데이터 안내로 옮기고, 과거 기온 그래프는 펼쳐 보기로 제공한다. 현재 관측일, 역사적 침수 발생일, 기온 그래프 기간은 해석에 필요하므로 유지한다. 실제 통계·점수는 변경하지 않는다.

## 기상 비교 지도와 동네 분석 연결 (2026-09-23 추가 승인)

사용자가 **기상 비교 지도 유지 + 연결된 동 목록 → 동네 분석**을 선택했다. 별도 기상 화면을 제거하는 앞선 제안은 실행하지 않는다.

- 메뉴를 ‘기상 비교’로 정리하고, 조회 종료일의 **같은 관측일 일 최고기온**을 관측소 위치와 목록에서 비교한다. 그날 결측은 관측 없음으로 표시하며 해당 관측소의 과거 마지막 값으로 대체하지 않는다. 색상 구간은 기온 표시용이며 취약도 등급이 아니다.
- 관측소를 선택하면 기존 현재 기상 연결 방식(현재 위치가 확인된 최근접 관측소)에 따른 부산 읍면동 목록을 표시한다. 각 동의 이름·구군·대표점과 거리에서 동네 분석으로 이동한다. 관측소가 속한 동 하나를 임의로 대표 동으로 선택하지 않는다.
- 동네 분석의 기온 카드에서 기상 비교로 이동하면 그 동에 연결된 관측소가 선택된다. 기상 지도→동네 분석→지도 왕복 시 선택한 관측소와 동을 유지한다. 기존 동의 분석으로 돌아가는 버튼도 제공한다.
- 현재 관측자료와 기존 취약도·보고서의 기준을 혼합하지 않는다. 새로운 위험 점수나 기온 기반 동별 순위를 산출하지 않는다. SGIS 실제 스냅샷은 변경하지 않았다.
- 관측값·비교일·동 연결을 동일한 스냅샷에서 응답하는 `/api/current-weather/comparison`을 추가했다. 자료 조회와 화면 전환은 로컬 자료만 읽으며 기존 3초 간격 수집·갱신 캐시 정책을 유지한다.

## 공식 대응 자료와 로컬 Qwen 사전 보고서 (2026-09-23)

사용자는 공식 자료와 오픈소스 모델을 함께 활용하는 방향을 선택했고, Vercel 공유를 위해 보고서를 미리 준비해 보여주는 방식에 동의했다. OpenAI API 키 활용을 검토한 후 **이미 설치된 Qwen을 사용**하도록 변경했다. 기존의 LLM 미사용 결정은 동별 대응 설명에 한해 이 결정으로 대체한다.
