# 시설자료 조사 및 별도 화면 연결

2026-09-22 확인. 기존 취약성 통계는 2024년이다. 사용자는 시설을 별도 현재 시설 화면에 제공하고 2024년 취약도·인구와 수치 비교하지 않는 방식을 승인했다.

- 국민안전24 공개 안전지도: 부산 16개 구·군 무더위쉼터 1,735개. 실제 행의 `year`는 모두 2026이다. 해운대구에서 `year=2024`를 전달해도 2026년 106개가 반환되므로 과거 자료로 해석하지 않는다. 공식 페이지: https://www.safekorea.go.kr/safekorea-kor/flsm/flsm/facilitiesSafteyMap.do?menuSn=2
- 공식 공개 조회 응답의 좌표·이용대상·운영시간을 확인했다. `scripts/collect_shelters.py`는 3초 간격으로 조회해 필요한 시설 속성만 연구용 원본 캐시에 보관한다. 직원 이름·계정 ID는 저장 대상에서 제외했다. **현재 시설 화면에만 연결했다.**
- 부산생활지도 공개 지도 목록: 무더위쉼터 2026-08-07, 우리동네 기후쉼터 2026-06-05, 폭염 그늘막 설치장소 2026-04-30. 2024년 재고로 소급하지 않는다. https://lifemap.busan.go.kr/li/index.do
- 공공데이터포털 북구 실내 무더위쉼터 자료의 ‘주기성 과거 데이터’에 2024-08-01 자료가 있다. 당시 파일 메타데이터까지 확인했으나 JSON 다운로드 응답은 비어 있었고, 부산 전체 자료도 아니다. https://www.data.go.kr/data/15131091/fileData.do
- 전국 무더위쉼터 표준데이터는 현재 링크형 API 제공이며, 현재 조회값만으로 2024년 시설 여부·이용대상을 복원할 수 없다. https://www.data.go.kr/data/15013199/standard.do

기존 동별 취약도 순위는 유지한다. 현재 시설 화면에는 취약도 색상·점수·순위·인구 대비 시설 수가 없다. 시설 수가 적다고 확충 필요지역으로 판정하지 않는다.

## 실제 연결 검증

- 국민안전24: 1,735개 좌표 유효, 누구나 이용 697개 / 특정인 이용 1,038개. 실시간 개방 상태는 아님.
- 부산생활지도: 그늘막 1,835개 중 부산 범위를 벗어난 좌표 1개 제외, 지도 표시 1,834개.
- 총 3,569개 위치 중 3개는 2025년 동 경계와 단일 매칭되지 않아 특정 동으로 배정하지 않음. 부산 전체 조회에는 표시함.
- 시설별 기준일과 수집 시점을 보관함. 그늘막 설치일을 현재 재고의 기준일과 혼동하지 않음.
- 같은 위치에 이름/시설번호가 다른 시설이 있을 수 있어 좌표만으로 중복 제거하지 않음.

- 지역 필터는 원본의 담당 구 코드가 아니라 등록 좌표의 경계 포함 여부를 따른다. 주소가 `부산광역시`로 시작하는 자료 중 주소상 구와 경계상 구가 다른 사례는 9개다. 예를 들어 금정구종합사회복지관 좌표는 해운대구 반여4동 경계 안에 있어, 해운대구 쉼터는 원본 구 조회의 106개와 달리 지도 필터에서 107개다. 좌표를 임의로 수정하지 않고 화면에 좌표 기준임을 표시한다.
